
# Basic Calculator Program in Python

This is a simple **Python program** that performs basic arithmetic operations. The program allows the user to input two numbers and choose an operation (addition, subtraction, multiplication, or division). It then performs the operation and displays the result.

## Features:
- **Addition** (`+`)
- **Subtraction** (`-`)
- **Multiplication** (`*`)
- **Division** (`/`)

## Prerequisites:
- Python 3.x installed on your machine.

## How to Run:
1. Clone this repository to your local machine.
2. Open a terminal and navigate to the project directory.
3. Run the program by typing:
   ```bash
   python basic_calculator.py
